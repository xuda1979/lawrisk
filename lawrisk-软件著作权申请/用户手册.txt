────────────────────────────────────────
1  引言
────────────────────────────────────────
1.1  编写目的
本手册面向 LawRisk 的最终用户（律所律师、法务、合同管理员），说明软件的安装、
卸载、操作步骤、配置方式与常见故障处理。读者只需具备基本的电脑与浏览器操作能力，
无需了解内部实现。

1.2  软件范围
LawRisk 提供以下能力：
- 合同风险评分（0-100 分，分商务/责任/数据合规/出口管制四个维度，每条结论可举证）；
- 双模板条款差异比对（按章节的增/删/改差异树，含语义摘要）；
- 与内置条款模板库（MSA、SaaS、NDA、DPA）的对照比对；
- 单文档风险审阅报告（Markdown / DOCX / HTML 导出）；
- 规则手册查询（查看全部判分规则）；
- 离线命令行（lawrisk-cli）完成上述大部分操作。

1.3  术语定义
- 维度（Dimension）：风险类别，即商务、责任、数据合规、出口管制四类之一。
- 严重度（Severity）：规则扣分的 1～3 级权重（轻/中/重）。
- 摘录（Excerpt）：命中的合同原文段落，用于核对结论出处。
- 整改建议（Mitigation）：针对该风险的修改建议。
- 差异树（Diff Tree）：左右两份文档按章节对齐后的差异明细视图。
- 基准模板（Template）：内置的 MSA / SaaS / NDA / DPA 标准条款集。

2  安装与卸载
────────────────────────────────────────
2.1  运行环境要求
- 操作系统：Linux / macOS / Windows；
- 硬件：x86_64 CPU、内存 ≥ 4GB、磁盘剩余 ≥ 1GB；
- 软件：Python 3.14 及以上（后端与命令行必需）；Node.js 22 及以上（仅在前端开发/构建时需要）；
- 浏览器：Chrome / Edge / Firefox 最新稳定版（使用 Web 界面时）。

2.2  安装步骤
2.2.1  后端（必装）
在项目根目录执行：
  python3.14 -m venv .venv
  source .venv/bin/activate        # Windows 用 .venv\Scripts\activate
  pip install -e ".[dev]"
2.2.2  启动 API 服务
  uvicorn lawrisk.api:app --reload --port 8000
服务启动后健康检查：浏览器打开 http://localhost:8000/api/health 应返回 {"status":"ok",...}。
2.2.3  前端（可选，使用 Web 界面时需要）
  cd frontend
  npm install
  npm run dev        # 开发模式，浏览器访问 http://localhost:5173
2.2.4  单端口生产模式（推荐给非开发者）
  cd frontend && npm run build        # 生成 frontend/dist
  cd ..
  .venv/bin/python -m lawrisk.serve --host 127.0.0.1 --port 8000
此时访问 http://localhost:8000 即同时获得页面与 API。
2.2.5  命令行工具
安装后自带 lawrisk-cli 命令，离线使用：
  lawrisk-cli score  tests/fixtures/risky_contract.docx
  lawrisk-cli review tests/fixtures/risky_contract.docx
  lawrisk-cli diff   tests/fixtures/template_a.docx tests/fixtures/template_b.docx
  lawrisk-cli rules

2.3  卸载
- 命令行工具：删除虚拟环境目录 .venv 即可（pip uninstall 可选）。
- 前端依赖：删除 frontend/node_modules 与 frontend/dist。
- 本软件无数据库、无配置残留，删除整个项目目录即完成卸载。

────────────────────────────────────────
3  操作说明（按功能模块）
────────────────────────────────────────
3.1  合同风险评分
1) 打开 Web 页面，在"评分"模式下点击上传，选择 DOCX / PDF / TXT 格式的合同文件
   （单文件 ≤ 20 MiB，可先试用 tests/fixtures/ 下的样例）；
2) 点击"评分"按钮；等待目标文档的文字版页面加载；
3) 结果区显示：风险总分（0-100）与等级（低/中/高）、四个维度的得分条、
   全部风险条目列表（每条含规则编号、维度、严重度、原文摘录与整改建议）；
4) 可导出 Markdown / DOCX / HTML 格式的审查报告存档或发送给客户。
要点：总分越低越安全；每条扣分均可在下方"原文摘录"中核对，不存在无法解释的结论。

3.2  双模板条款差异比对
1) 切换到"对比"模式，分别选择左（模板 A）与右（模板 B）两份文档；
   两份文档会被解析、按章节对齐；
2) 页面以"并排视图"显示差异行：绿色为新增、红色为删除、黄色为修改，
   词级高亮展示具体改动位置；右侧可切换"差异树"视图查看层级；
3) 页面顶部横幅同时给出两份文档各自的风险得分与关键事实（币种、期限、
   准据法、仲裁地）；
4) 可导出 Markdown 差异报告。
要点：差异树按章节组织，行号与双方原文一一对应，便于律师逐条审阅。

3.3  模板库对照
1) 在"模板库"页选择基准模板（MSA / SaaS / NDA / DPA）；
2) 上传一份待比对合同；
3) 系统输出该合同与基准模板的差异明细及风险面板，用于快速定位与标准结构
   的偏离条款。
要点：适合"将新合同套用到机构标准模板"的日常场景。

3.4  单文档风险审阅
1) 切换到"审阅"模式，上传单份合同；
2) 系统按合同章节（如"第1条 定义""第2条 服务"）归组展示全部风险发现，
   每个发现均可展开查看原文摘录与整改建议；
3) 可导出 Markdown / DOCX / HTML 三种格式的《风险审阅报告》。
要点：适合把一份合同整体交给客户或同事的场景，报告自带章节目录。

3.5  规则手册查询
在"规则手册"页可浏览全部 23 条判分规则（编号、维度、严重度、判定条件、
扣分原因、整改建议），并可搜索定位。该功能帮助用户理解评分依据、向客户
解释结论，也用于律所内部培训。

3.6  命令行操作（lawrisk-cli）
- lawrisk-cli score 文件                            # 打印得分、等级、发现数与哈希
- lawrisk-cli review 文件                           # 输出 Markdown 审阅报告
- lawrisk-cli diff 文件A 文件B                       # 输出 Markdown 差异报告与双方风险
- lawrisk-cli rules                                 # 打印规则手册
- 全部子命令加 --json 可输出机器可读 JSON；diff 支持 --name-a/--name-b 自定义标签。

3.7  关键事实面板（P4）
在评分/比对/审阅结果里，页面顶部展示合同的关键业务字段：交易币种、合同期限、
准据法、仲裁地，每一字段均附来源原文段落，供快速抽查。

4  配置与参数
────────────────────────────────────────
| 环境变量 / 参数        | 取值示例                     | 说明 |
|------------------------|------------------------------|------|
| LAWRISK_LLM            | 0（默认）/ 1                 | 是否启用 LLM 摘要层；默认关闭，全程离线 |
| LAWRISK_LLM_PROVIDER   | mock（默认）                 | 摘要器实现；实现自定义摘要器后注册即可 |
| LAWRISK_SERVE_SPA      | 1（默认）/ 0                 | 单端口服务是否挂载前端静态页面 |
| uvicorn --port         | 8000                         | API 监听端口 |
| upload 大小限制         | 20 MiB（内置）               | 超限返回 413，不可调（代码常量） |
| 开发/生产形态         | uvicorn+lit dev / build+serve | 见安装章节 2.2 |
其他说明：
- 全部输入文件必须为 DOCX / PDF / TXT 之一；其他格式请先转换为上述格式。
- 引擎版本固定为 lawrisk-engine-v1，评分哈希随内容与版本唯一。

────────────────────────────────────────
5  故障处理与 FAQ
────────────────────────────────────────
5.1  常见问题
Q1 上传文件提示"文件过大（413）"？
A  单文件上限 20 MiB。请压缩文档或拆分章节后上传；PDF 请检查是否含大量扫描图片。

Q2 页面打不开 / localhost 拒绝连接？
A  确认后端已启动且端口未被占用（uvicorn --port 8000）；生产模式请先执行
   cd frontend && npm run build 生成前端产物，再启动 serve。

Q3 解析出来的段落为空或明显缺少内容？
A  对于加密 PDF 或纯图片扫描件，先导出为可复制文字的 PDF/DOCX；DOCX 表格内容
   虽会读取，但过于复杂的嵌套表格请先转换为普通文本段落。

Q4 为什么我的合同得了高分？
A  每一条扣分都能在结果列表中点击查看"原文摘录"与"整改建议"。常见高分原因：
   自动续约、单方终止/改价/修订、责任上限、免责、无服务保障、数据处理无边界的
   表述。请逐条核对后按建议修改。

Q5 结果与上次不同？
A  本引擎是确定性的（含 SHA-256 校验哈希），同一份文件必然得到同一结果。
   若不同，说明输入的文档内容有差异（如重新导出时发生了格式变化），请核对文件。

Q6 我可以用它出具法律意见吗？
A  不能。本软件是风险检测与条款差异辅助工具，识别结果需由执业律师复核，
   不构成法律意见。

Q7 不想上传到任何服务器，能离线用吗？
A  可以。默认全部本地运行、全程不联网；也可以用 lawrisk-cli 在命令行离线完成
   评分、审阅、比对与规则查询。

Q8 为什么有的维度没有扣分？
A  维度得分由该维度下命中的规则决定；未命中即 0 分，属于正常情况。
